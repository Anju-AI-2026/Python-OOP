# Python Object-Oriented Programming Repository

This repository contains Python programs developed while learning **Object-Oriented Programming (OOP)** concepts. Each folder focuses on a specific OOP concept and includes practical examples to improve programming and problem-solving skills.

---

## About

The purpose of this repository is to practice and understand:

* Classes and Objects
* Constructors (`__init__`)
* Instance Variables
* Methods
* Encapsulation
* Magic Methods
* Class Methods
* Static Methods
* Properties (`@property`)

---

## Repository Structure

| Folder                        | Description                                                                              |
| ----------------------------- | ---------------------------------------------------------------------------------------- |
| `01_Date_Class`               | Date class implementation with date-related operations                                   |
| `02_Bank_Class`               | Bank account management system with deposit and withdrawal operations                    |
| `03_Employee_Class`           | Employee class to manage employee details and operations                                 |
| `04_Robot_Class`              | Robot simulation with movement and battery-related functionality                         |
| `05_Student_Classs`           | Student information management using OOP concepts                                        |
| `06_magic_methods`            | Practice programs for Python magic methods such as `__str__`, `__len__`, `__add__`, etc. |
| `07_class_and_static_methods` | Examples demonstrating the use of `@classmethod` and `@staticmethod`                     |
| `08_property_methods`         | Programs showing how to use `@property`, getters, setters, and validation                |
