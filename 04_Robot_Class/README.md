# 🤖 Robot Control System (Python OOP)

## 📌 Project Overview

This project is a simple Robot Control System developed using Python and Object-Oriented Programming (OOP). The program simulates a robot that can move, detect obstacles, recharge itself, and display its current status.

---

## 🧠 Concepts Used

- Classes and Objects
- Constructors (`__init__`)
- Methods
- Conditional Statements
- Loops
- Menu-driven Programming
- State Management

---

## 🚀 Features

- Create a robot with a name and ID
- Move the robot in four directions:
  - Up
  - Down
  - Left
  - Right
- Detect obstacles
- Monitor battery level
- Recharge robot at base position
- Return robot to base
- Display robot details
- Interactive menu system
