# Properties in Python OOP

## Overview

This folder contains programs that demonstrate **properties in Python OOP** using the `@property` decorator. Properties provide a clean and controlled way to access and manage object attributes.

## Programs

### 1. `smartphone_property.py`

* **Concept:** Basic `@property`
* Accesses a private attribute using a property getter.

> More property-based programs will be added as I continue learning Python OOP.

## Learning Outcomes

* Understand the purpose of `@property`.
* Access private attributes safely.
* Write cleaner and more Pythonic OOP code.
