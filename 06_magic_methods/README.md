# Magic Methods in Python OOP

## Overview

This folder contains programs that demonstrate Python's **magic methods (dunder methods)**. These methods enable custom objects to work naturally with Python's built-in functions and operators.

## Programs

### 1. `book_str_method.py`

* **Concept:** `__str__()`
* Returns a readable string representation of a `Book` object when `print(object)` is used.

### 2. `shopping_cart_len_method.py`

* **Concept:** `__len__()`
* Returns the total number of items in a shopping cart when `len(object)` is called.

> More magic method programs will be added as I continue learning Python OOP.

## Learning Outcomes

* Understand Python magic methods.
* Make custom classes work with built-in functions.
* Improve object readability and functionality.
